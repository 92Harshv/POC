 =========================================================
   ROAD RASH - MOTO BRAWLER
   Motorcycle Racing with Combat
 =========================================================

 QUICK START (Two Options):
 ──────────────────────────

 Option A — One-Click Install (Recommended):
   1. Double-click  install.bat
   2. Wait ~1 minute for setup
   3. Launch from Desktop shortcut

 Option B — Run Directly (Python already installed):
   1. Open Command Prompt in this folder
   2. Run:  pip install pygame
   3. Run:  python game.py

 BUILD STANDALONE EXE:
 ─────────────────────
   Double-click  build_exe.bat
   → Produces  dist\RoadRash.exe  (share without Python)

 CONTROLS:
 ─────────
   Accelerate     ↑ / W
   Brake          ↓ / S
   Steer Left     ← / A
   Steer Right    → / D
   Punch Left     Z
   Punch Right    X
   Kick Left      Q
   Kick Right     E
   Nitro Boost    SHIFT
   Pause          P / ESC

 GAMEPLAY TIPS:
 ──────────────
   • Get close to enemies, then punch/kick in their direction
   • Chain 3+ hits for combo bonus damage
   • Stay on the road — going off-road slows you down
   • Earn cash by finishing high and knocking rivals off
   • 3 levels of increasing difficulty

 REQUIREMENTS:
 ─────────────
   Windows 10/11 (64-bit)
   Python 3.9+  (install.bat downloads it automatically)
   ~50 MB disk space
